# 造物星球 · 6-8 岁项目路线图（含市面竞品分析）

> 目标：在不引入新运行时能力的前提下，先把"图形化积木启蒙"阶段（6-8 岁）填满到 **10+ 大类、50+ 项目**，并标注每类所需的扩展工作量，作为后续开发排期依据。
> 现状：已上线 **61 个项目**（stage-6-8：分类1·序列 11/11、分类2·循环 10/10、分类3·画笔 10/10、分类4·事件 10/10、分类5·条件 10/10、分类6·游戏 10/10），运行基座为 Blockly + 二零（海龟/角色混合模型）。详见 `docs/plan-track.md`。

## 一、市面主流少儿编程产品调研（6-8 岁）

| 产品 | 适龄 | 核心体裁 / 模块 | 关键积木概念 | 对我们的启发 |
|---|---|---|---|---|
| **ScratchJr**（Tufts/MIT，5-7 岁） | 5-7 | Collage（拼贴）/ Story（故事）/ Game（游戏）三大体裁 | 移动/转向/跳/回家、重复/永远重复、说话气泡、页面、点击/碰撞/消息事件 | 用"体裁"而非"语法"组织内容；故事+游戏双主线 |
| **Code.org Course A**（K-1） | 5-7 | Sequencing（Happy Maps）→ Loops（Happy Loops / Ocean Scene）→ Events（The Big Event Jr.） | 序列、循环、事件，对齐 CSTA 1A-AP-09~14 | 概念严格按"序列→循环→事件→条件"梯度递进 |
| **Blockly Games**（Google→Raspberry Pi） | 无经验儿童 | Puzzle→Maze→Bird→Turtle→Movie→Music→Pond | 序列、循环+条件、控制流、嵌套循环几何、数学方程、函数、JS | 海龟绘图（Turtle）是几何/循环的最佳载体；难度平滑过渡 |
| **西瓜创客**（6-15，图形化 6-9） | 6-9 | 12 个跨学科主题项目、70+ 软件作品 + 16 硬件作品 | STEAM 融合（科学/技术/工程/艺术/数学），PBL 项目制，CLS 创造力螺旋 | 用"跨学科主题"包装编程，提升兴趣与知识迁移 |
| **编程猫 / 核桃 / 咕咚**（6-12） | 6-12 | 图形化创意编程、IP 化、动画剧情 | 强趣味性降低入门门槛 | 低龄段靠"趣味 IP + 强引导"留人 |

**行业共识（来自多家机构公开数据）**：
- 6-8 岁 = **图形化编程入门期**，目标定位为"逻辑思维启蒙 + 兴趣培养"，家庭需每周 2-3 小时陪伴练习。
- 完课率普遍仅 30-40%，主因是家庭缺乏持续陪伴，而非课程质量——因此**强引导、即时反馈、可看示范**是本产品已验证的正确方向。
- 能力阶梯高度一致：**序列 → 循环 → 事件 → 条件 → 函数/抽象 →（进阶）文本代码**。
- 题材高度一致：**故事、游戏、艺术绘图、音乐、数学、科学模拟** 六条主线。

**结论**：造物星球应沿用"概念梯度 + 体裁包装"双轴设计，题材覆盖上述六主线，并用 PBL（一个有趣挑战贯穿整课）组织，与市面头部产品对齐的同时，发挥我们"无广告、纯前端、本地存储、沉浸式"的差异化优势。

## 二、造物星球现有能力基座

**已可直接调用的运行时原语（`lib/runtime.ts`）**：
- 动作：`move(steps)` 移动 · `turn(degrees)` 转向 · `goto(x,y)` 到坐标 · `gotoMouse()` 飞向鼠标 · `gotoStar(i)` 飞向星星 · `say(text,seconds)` 说话 · `wait(seconds)` 等待
- 画笔：`penDown()` 落笔 · `penUp()` 抬笔 · `setPenColor(hue)` 设色 · `changePenColor(delta)` 变色
- 判定：`touchingStar()` 是否碰到星星（布尔，用于"如果…那么"条件）
- 事件：`whenStart` 当开始运行 · `whenStageClicked` 当舞台被点击
- 控制积木（Blockly 自带）：`controls_repeat_ext` 重复 N 次 · `controls_if` 如果…那么

**可支撑度分层标注**（用于下文项目清单）：
- ✅ **即刻可做**：无需改 runtime，仅靠现有积木组合即可实现。
- 🔧 **需小扩展**：加少量运行时能力（变量/计分、键盘事件、多角色、随机数、画笔粗细、音效等）。
- 🚀 **需较大扩展**：物理、多场景/页面、文本 JS、AI 等。

## 四、难度与概念进阶地图

```
L1 序列      大类1（方向/顺序）             → 已验证：hello
L2 循环     大类2（重复）+ 大类3（绘图）   → 已验证：rainbow
L3 事件     大类4（点击/触发）             → 已验证：click_jump / two_events / key_forward
L4 条件     大类5（如果…那么）            → 已验证：if_red_stop / click_left_right / collect3
L5 综合游戏 大类6（收集/闯关）            → 已验证：maze_exit / collect_apples / traffic_police
L6 表达     大类7（故事）+ 大类8（音乐🔧）
L7 学科融合 大类9（数学）+ 大类10（科学🔧）
L8 创造     大类11（PBL 综合）
```
每一级都可以用前一级的积木组合出新项目，保证"学过的都能用上"。

## 五、落地优先级建议（先做什么）

**第一阶段（现在就能做，零运行时改动）**——把 ✅ 项目补齐，快速把 6-8 岁阶段从 3 个扩到 ~30 个：
- 大类 1（10）、大类 2（10）、大类 3 未上线部分（9）、大类 4 的 ✅ 部分（约 6）、大类 5 的 ✅ 部分（约 6）、大类 6（10）、大类 7 的 ✅ 部分（约 6）。
- 路线：每个项目复用 `courses/index.ts` 的 `CourseProject` 结构 + `lib/steps.ts` 的 `computeSteps` 纯函数做步骤判定，并配"看示范"XML。

**第二阶段（小扩展，性价比最高）**——加 4 个轻量运行时能力即可解锁 ~35 个项目：
1. `变量 / 计分`（支持奇偶、计数、计算器）
2. `键盘事件`（whenKeyPressed）
3. `多角色 / 显隐 / 大小`（支持对话、魔术、逃跑）
4. `音效`（playTone，解锁整个音乐大类）

**第三阶段（较大扩展，做差异化）**——科学模拟与文本 JS 过渡，对应 9-12 岁阶段铺垫。

## 六、与市面产品的差异化定位

| 维度 | 市面常见做法 | 造物星球做法 |
|---|---|---|
| 商业模式 | 付费年课、完课率低 | 免费、无广告、本地存储、可随时练 |
| 引导方式 | 真人/AI 双师视频 | 内置"看示范" + 步骤判定 + 即时日志反馈（已验证有效） |
| 技术栈 | 自研闭源工具 | 开源 Blockly + 纯前端，家长可审计、孩子可过渡到 JS |
| 内容节奏 | 大体量课程体系 | 小步快跑、单项目即闭环、按学龄段分层 |
| 数据 | 云端行为大数据 | 完全本地，隐私友好 |

**一句话定位**：做"孩子自己就能玩明白、家长放心不操心"的沉浸式编程练习场，用市面验证过的概念梯度与体裁，配上我们更轻、更稳、更隐私友好的实现。
